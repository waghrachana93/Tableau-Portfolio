# Sales Dashboard (Tableau Project)

## 📊 Project Overview
This Tableau dashboard provides an interactive analysis of sales performance across regions, segments, and managers.  
It compares **2022 vs 2021 (CY vs PY)** trends and highlights KPIs such as Total Sales, Profit, and Quantity.

## 🚀 Key Features
- **KPI Trend Overview**: Year-over-Year (YOY) comparison with max/min month highlights.
- **Sales & Profit Distribution by State**: Geographic breakdown of performance across US states.
- **Segment Analysis**: Monthly sales trends segmented by Consumer, Corporate, and Home Office.
- **Manager & Region Performance**: Regional contribution to overall sales and profit.
- **Above/Below Average States**: Quick identification of states performing above or below average.

## 📈 KPIs (2022 vs 2021)
- **Total Sales**: $733K (+20.36% YOY)
- **Total Profit**: $93K (+14.24% YOY)
- **Total Quantity**: 12K (+26.83% YOY)
